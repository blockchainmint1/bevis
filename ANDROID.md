# BEVIS — Android (APK / AAB) build guide

The Android app is a thin Capacitor shell around the live web app at
`https://app.bevis.sg/app`. Web changes ship instantly; you only rebuild the
binary when the bundle id, icons, splash, permissions, plugins, or the URL
in `capacitor.config.ts` change.

| Setting     | Value          |
| ----------- | -------------- |
| App id      | `sg.bevis.app` |
| App name    | `BEVIS`        |
| Loads       | `https://app.bevis.sg/app` |
| Min SDK     | Capacitor 8 default (Android 6+) |

## 1. One-time local setup

Requires **JDK 21** and **Android Studio** (or just the command line tools).

```bash
bun install
bun run build            # creates .output/public
bun run cap:add:android  # one-time — creates ./android
bun run cap:sync
```

## 2. Icons and splash

Source art lives in `resources/` (`icon.png`, `icon-foreground.png`,
`icon-background.png`, `splash.png`, `splash-dark.png`). Regenerate every
density with:

```bash
bun run cap:assets
```

## 3. Build

```bash
bun run android:apk       # debug APK for sideloading / testing
bun run android:release   # release AAB for Play, needs signing config
bun run android:open      # open the project in Android Studio
```

Outputs:

- Debug APK — `android/app/build/outputs/apk/debug/app-debug.apk`
- Release AAB — `android/app/build/outputs/bundle/release/app-release.aab`

Sideload a debug build: `adb install -r android/app/build/outputs/apk/debug/app-debug.apk`

## 4. Signing (once, keep this key forever)

```bash
keytool -genkey -v -keystore bevis.keystore -alias bevis \
  -keyalg RSA -keysize 2048 -validity 10000
```

Store `bevis.keystore` **outside** the repo. For CI, base64 it:

```bash
base64 -i bevis.keystore | pbcopy
```

and add these GitHub repository secrets:

| Secret | Value |
| ------ | ----- |
| `ANDROID_KEYSTORE_BASE64` | the base64 blob above |
| `ANDROID_STORE_PASSWORD`  | keystore password |
| `ANDROID_KEY_ALIAS`       | `bevis` |
| `ANDROID_KEY_PASSWORD`    | key password |

## 5. Git / CI workflow

`android/` is **git-ignored** — it is regenerated by `cap add android`, so
nothing native needs to live in the repo.

```text
feature branch  ──▶ PR ──▶ main
                              │
                              ├─ push to main   → CI builds a debug APK artifact
                              └─ push tag v1.4.0 → CI builds signed AAB + APK artifacts
```

Day to day:

```bash
git checkout -b feat/whatever
# ...work, Lovable also commits to the connected branch...
git push -u origin feat/whatever      # open PR, merge to main
```

Cutting a release:

```bash
git checkout main && git pull
git tag v1.4.0 -m "BEVIS 1.4.0"
git push origin v1.4.0                # CI produces the signed bundle
```

Then download the `bevis-release` artifact from the Actions run and upload
`app-release.aab` to the Play Console.

Bump `versionName`/`versionCode` in `android/app/build.gradle` before tagging
(or let Play's internal testing track handle increments).

## 6. Testing against preview instead of production

Edit `capacitor.config.ts` → `server.url` to
`https://id-preview--a663349c-4f40-4b3a-8730-df21f057abce.lovable.app/app`,
then `bun run cap:sync && bun run android:apk`. Revert before releasing.

## 7. Permissions

Capacitor plugins inject most of them. Verify in
`android/app/src/main/AndroidManifest.xml`:

- `INTERNET` (required)
- `CAMERA` — QR scanning
- `POST_NOTIFICATIONS` — Android 13+ push

Push notifications additionally need `google-services.json` from Firebase
dropped into `android/app/`.
